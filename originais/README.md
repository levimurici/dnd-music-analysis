# originais/

Coloque aqui o PDF ou a foto da partitura original em **tom de concerto**
(ex.: `originais/garota_de_ipanema.pdf`) e peça ao agente: "faça o fluxo completo da garota_de_ipanema".

O conteúdo desta pasta não vai para o git (pode ter direitos autorais).
As partituras geradas pelas skills ficam em `partituras/`.
